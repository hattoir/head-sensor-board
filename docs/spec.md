# head-sensor-board — 仕様と部品表（Stage 3 更新版）

**Floor Watch の「頭のセンサー基板（試作用）」。** ToF の崖判定（HG-H2 の T6-1〜T6-4）と、斜め LED の追試（T4）に使う。**本番の基板ではない。**
状態: **Stage 3（外形 40×25 mm と部品配置案。配線なし）— User の確認待ち。** 回路図は ERC 0（Stage 2、User 確認済み）。配線・DRC（エラー 0）・ガーバーには進んでいない。**ガーバーは ToF 小基板のピン配置が分かるまで出さない。**

確認状態の印: ✅ 原本（データシート・公式図面）を読んで確認 ／ 🟡 販売ページ・Wiki で確認（原本は未確認）／ 🔴 未確認・仮定 ／ ⚪ 資料に記載なし

## 運用上の注意（User 指示 2026-10-01。README と回路図の注記 H にも同じ文を残した）

1. **5V は試験用の選択肢で、既定は 3V3。** 5V にしたときの合計 **493 mA は USB 2.0 の 500 mA ぎりぎり**（余裕 7 mA）。5V の取り出しは、半田ジャンパー SJ1/SJ2 の 5V 側パッドだけ（既定では開放）。XIAO の 5V ピンの電流能力は未確認。
2. **3V3 は、Wi-Fi 送信・撮影・LED 100 %・ToF ピークを同時にしない運用が必要。** 実機で XIAO の 5V 入力電流を測るまで（§4.3。Seeed の条件不明の 0.65 A を上限と見ると 808 mA = 700 mA の 115 %）。
3. **ToF 小基板のピン配置は未確認**（ヘッダの並びは仮）。ガーバーは出さない。

## 1. 仕様

| 項目 | 内容 |
|---|---|
| 電源 | **既定: XIAO の 3V3 ピンだけ**。5V ピンは SJ1/SJ2 の 5V パッド（既定では開放）だけにつながる |
| マイコン | XIAO ESP32S3 Sense（U1）を、2×7 のピンソケット（またはピンヘッダ）で載せる。直付けしない。2.54 mm ピッチ、穴の行間隔 15.24 mm |
| ToF | VL53L1X 小基板 ×2。**1×6 ヘッダ J1/J2（VIN, GND, SCL, SDA, XSHUT, GPIO1）からジャンパー線で引き出す**（並びは仮）。XSHUT を GPIO から個別制御。GPIO1 は 0 Ω リンク（DNP）で D8/D9 につなげる |
| LED | NSSW157T ×2（D1/D2、基板上）。電流制限抵抗 + N-ch MOSFET でスイッチ、GPIO から PWM 調光。**外付け LED 用ヘッダ J3/J4（pin1 = +、pin2 = −）**。D1/D2 か外付けの**どちらか一方**を使う（両方だと電流を分け合う） |
| LED の電源 | 各チャンネル 3 パッドの半田ジャンパー（SJ1/SJ2）。**既定は 1-2 をつないだ状態 = 3V3（R1/R2 = 20 Ω 0603）**。5V にするときは 1-2 の橋を切り、2-3 をはんだでつなぐ（R3/R4 = 33 Ω 2010 は実装済み） |
| I2C プルアップ | R13/R14（3.3 kΩ）を置き、**既定は未実装（DNP）**。XSHUT のプルアップ（10 kΩ）は実装 |
| テストポイント | TP1 3V3、TP2 GND、TP3 SCL、TP4 SDA、TP5 XSHUT_L、TP6 XSHUT_R、TP7 ILED_L、TP8 ILED_R（電流の電圧 = 1 mV/mA） |
| 基板 | 2 層、1.6 mm。**外形 40×25 mm（角 R1、M2 穴 2 個）、変数で作り直せるように**。KiCad 10.0.1 |

**LED チャンネルの回路（L / R 同じ）**
```
 +3V3 ─ R1(20Ω 0603) ─┐ 1
                       SJ ─2─ LEDA ─┬─ D(NSSW157T) ─┬─ LEDK ─ Q(AO3400A).D
 +5V  ─ R3(33Ω 2010) ─┘ 3           └─ J(+)          └─ J(−)            G ← 220Ω ← GPIO(PWM)、100kΩ で GND
                                                                          S ─ SENSE ─ R(1Ω) ─ GND   （TP ILED = SENSE）
```
J3/J4 のピンは抵抗の**あと**のノード（電流制限済み）。**J3/J4 の + と − を短絡しない**（R1 が約 0.49 W、R3 が約 0.71 W を消費して焼ける）。

### 4.2 LED の電流（3V3 と 5V）

| 電源 | 抵抗 | 電流 最小 / 公称 / 最大（LED 1 個） | 抵抗の最大損失（定格比） | 80 mA 比（光量） |
|---|---|---|---|---|
| **3V3（既定）** | R1/R2 = **20 Ω 0603**（0.1 W） | 8.5 / 23.6 / 38.8 mA（絶対最大 150 mA の 6 / 16 / **26 %**） | 30 mW（**30 %**） | 11 / **30** / 49 % |
| **5V（SJ で選択）** | R3/R4 = **33 Ω 2010**（0.5 W） | 45.0 / 59.0 / 73.0 mA（同 30 / 39 / **49 %**） | 176 mW（**35 %**） | 56 / **74** / 91 % |

- 20 Ω は「最小電流が 80 mA の 10 % 以上」を保つ最大の E24 値（22 Ω 以上は 9.8 % 以下）。
- **5V 側の抵抗の選び方**（`led_budget.py`）: ① 最悪時の損失 ≦ 定格の 50 % ② 最大電流 ≦ 100 mA ③ 最小電流 ≧ 8 mA ④ LED の Tj ≦ 120 °C（Ta 50 °C 仮定）⑤ **5V の合計（LED 2 個の最大 + XIAO の撮影ピーク 347 mA）≦ USB 2.0 の 500 mA**。この基準で最小の E24 値は、**1206 なら 56 Ω**（28 / 37 / 46 mA、損失 119 mW = 48 %）、**2010 なら 33 Ω**。User の指示が「1206 以上」なので、明るい方の **2010 / 33 Ω** を採用した。1206 に 33 Ω を載せると 176 mW で定格の 70 % になり ① を満たさない。2010 / 24 Ω（96 %）は ⑤ を満たさない（5V 合計 536 mA）。
- **5V 用に 3V3 用の 20 Ω を使うと**最大 109 mA、0603 が 238 mW（定格の 238 %）で焼ける。SJ と R1/R3 は回路図のとおりに組む（SJ を切り替えれば抵抗も切り替わる構造）。
- LED の損失は最大 202 mW（定格 510 mW）、Tj ≒ 69 °C（Ta 50 °C、上限 120 °C）（5V 時）。

### 4.3 3V3 から取る電流の合計（Wi-Fi・カメラのピークを含む）

基板側（外部負荷）: LED（3V3、最大）77.6 + ToF ピーク 2×40 + XSHUT プルアップ 0.7 = **158 mA**（LED を 5V にすると **81 mA**）。XIAO 側は Seeed の値。3V3 が LDO なら 3V3 側の電流 ≒ 入力側（撮影ピークが 5V で 347 mA、3.8V で 366 mA とほぼ同じ = 入力電圧に依らない = LDO 的。**レギュレータの型番は Seeed に記載なし = 未確認**）。

| 想定（XIAO 自身） | XIAO 分 | 合計（LED=3V3） | 合計（LED=5V） | 出典・確認 |
|---|---|---|---|---|
| A. Webcam 平均 | 140 mA | 298 mA（43 %） | 221 mA（32 %） | Seeed wiki 🟡 |
| B. Webcam 撮影ピーク（バッテリー側の値） | 366 mA | **524 mA（75 %）** | 447 mA（64 %） | Seeed wiki 🟡 |
| C. カメラ比較表の MAX（OV2640 ≒ 0.65 A） | 650 mA | **808 mA（115 %）** | 731 mA（104 %） | Seeed wiki、**測定条件の記載なし = 未確認** |
| D. Wi-Fi 送信ピーク（チップ単体・参考） | 340 mA | 498 mA（71 %） | 421 mA（60 %） | Espressif ✅（カメラ・PSRAM・Flash は含まない） |

（% は Seeed の「3V3 で 700 mA」に対する割合。）
- **B までなら 524 mA で 700 mA 以内。C を上限と見ると 808 mA で超える**（LED を 5V にしても 731 mA）。C の条件は不明なので、**実機で XIAO の 5V 入力電流を測るまで、Wi-Fi 送信・撮影・LED 100 %・ToF ピークを同時にしない運用が安全側**。測定の依頼は ENTRY-K-0001（Engineering）。
- **5V 側**（LED を 5V にした場合）: LED 2 個の最大 146 mA + XIAO の撮影ピーク 347 mA = **493 mA（USB 2.0 の 500 mA 以内、余裕 7 mA）**。XIAO の 5V ピンの電流能力は Seeed に記載なし = **未確認**（5V を選ぶ前に確認）。

### 4.4 GPIO と MOSFET のゲート駆動

- GPIO は LED 電流を流さない（MOSFET のゲートのみ）。ゲート充電のピークは 3.3 V / 220 Ω = 15 mA（ns 単位）、XSHUT の L 出力は 0.33 mA。GPIO の IOH 40 mA / IOL 28 mA（ESP32-S3 DS v2.2 表 5-4）に対して十分小さい。
- **3.3 V ロジックで確実に駆動できる**: ESP32-S3 の VOH 最小 = 0.8 × VDD = 2.64 V（表 5-4）。
  - **AO3400A**（Alpha & Omega Rev 3.1、2023-07）: VGS(th) 0.65 / 1.05 / 1.45 V（最小/typ/最大）、RDS(on) < 48 mΩ @VGS=2.5 V・< 32 mΩ @4.5 V、VGS 最大 ±12 V、VDS 30 V、ID 5.7 A。2.64 V は VGS(th) 最大の 1.8 倍、RDS(on) の規定（2.5 V）以上 ✅
  - **Si2302CDS**（Vishay S12-2336 Rev D）: VGS(th) 0.40〜0.85 V、RDS(on) < 75 mΩ @2.5 V・< 57 mΩ @4.5 V、VGS 最大 ±8 V、VDS 20 V、ID 2.6 A。2.64 V は VGS(th) 最大の 3.1 倍 ✅
  - どちらも SOT-23、**1 = G、2 = S、3 = D**（Vishay は原本に明記。AOS の図は端子名のみで、番号は SOT-23 の標準配置）。LED 電流 最大 73 mA での Vds 降下は約 5 mV（0.075 Ω × 73 mA）。
- ゲート直列 220 Ω + 100 kΩ プルダウン: 起動中・リセット中は GPIO が浮くので LED を消しておく。

| XIAO は USB-C が外に向くように | **左の縁**に USB-C。モジュールの端は基板の縁から 0.6 mm 内側（銀色の枠が縁にかからないように）。ケーブルは左へ出る |
| TP1〜TP8 と電流検出の TP7/TP8 は、測定しやすい側に | TP は**全部上面**。上の縁: TP1 3V3・TP3 SCL・TP4 SDA、下の縁: TP5 XSHUT_L・TP6 XSHUT_R、右のゾーン（背の高い部品が無い側）: **TP7 ILED_L・TP8 ILED_R・TP2 GND を縦に並べた 1 か所**（電流は GND を基準に測るので GND を隣に置いた）。名前は TP の横に刻印（3V3 / SCL / SDA / XSL / XSR / ILL / ILR / GND） |
| 配置図を PNG で出して止まる | 上の 3 枚。配線・DRC エラー 0・ガーバーには進んでいない |

### 6.2 配置の方針

- **向きの定義**: 上面から見て USB-C を左、LED の縁を右にする。**下半分 = L チャンネル**（XIAO の D0〜D6 の列に近い側）、**上半分 = R チャンネル**（L の鏡像）。**回路図の L/R は基板上の位置の名前で、ロボットの左右とは限らない**（ToF・LED はジャンパー線で自由に左右へ引けるので、取り付けのときに合わせる。合わなければ firmware のチャンネルを入れ替える）。
- **XIAO の下（ソケットの内側）**に、高さ 0.9 mm 以下の 0603 / 2010 だけを置いた（R3〜R8、R11〜R16、C1〜C3）。XIAO の外形ではなく**ピン列の帯だけ**をコートヤードにしたため（`libs/` の XIAO フットプリント）。ソケットの高さは 8.5 mm と仮定（🔴）。ピンヘッダ直付けだと隙間が約 2.5 mm になるので、0.9 mm 以下の部品に限った。
- **上面に全部品**（SMD も THT も）。**裏面は部品なし**（凡例の刻印だけ）= Stage 4 で GND ベタと配線に使える。
- SJ1/SJ2 と R1〜R4（LED の電流制限）は右のゾーンの上下（半田ジャンパーは上面で触れる）。MOSFET（Q1/Q2）は LED のそば、電流検出 R9/R10 は MOSFET のすぐ隣。ゲートの 220 Ω / 100 kΩ は XIAO の D2/D3 の真上（XIAO の下）。
- M2 穴は **LED の縁側の 2 つの角**（対角ではなく右の上下）。左の角は XIAO のピン列の帯と重なる。穴のコートヤードは標準の半径 2.4 mm（M2 なべ小ねじの頭を想定。🔴）。
- 刻印（上面）: TP の名前、SJ の「3V3 / 5V」、J3/J4 の「+ / −」、LED の「L / R」、J1/J2 の部品名。小さい部品の部品名は Fab 層（刻印の重なり防止）。裏面の刻印: 「HSB REV A / L=LOWER / R=UPPER / TOF ORDER / TBD」。

### 6.3 高さと面積

- **高さの制限（6 mm 以下）は LED だけ**: NSSW157T = **0.52 mm ✅**（Nichia p.4）。ほかの部品（XIAO + ソケット 約 23 mm、ヘッダ、MOSFET、抵抗）には適用しない（User 指示）。
- **面積**: 40×25 = 1000 mm²。上面の部品で**ぎりぎり**（上の「下限」）。余裕が無いので、Stage 4 の配線で必要ならビア・配線の都合で再配置する可能性がある。部品を替えると（ソケット・ヘッダの寸法など）収まらなくなることがある。

### 6.4 Stage 4 で効きそうな点（配線の見通し）

- 上面の配線と裏面の GND ベタ（ビアでつなぐ）。XIAO の下の配線は、ピン列の間（0.74 mm の隙間に 0.25 mm の線）を通す。
- **基板の上下をまたぐ信号**: D0〜D6 の列は下側なので、上側の J2（R）・R チャンネルへ行く SDA / SCL / XSHUT_R / GPIO1 と PWM_R は XIAO の内側か裏面を通って上へ渡す。
- +3V3 は多くの点（J1/J2 の VIN、R1/R2、プルアップ、TP1、C1〜C3）に届く幹線になる（0.4 mm 以上）。+5V は R3/R4 → SJ だけ。
- LED の電流が流れる線（LEDA / LEDK / SENSE、最大 73 mA）は 0.3 mm 以上。

## 8. 未確認・仮定の一覧

1. **ToF 小基板のピン配置**、基板上のプルアップ・LDO・レベルシフタの有無、I2C アドレス、実寸 — 販売ページ（Amazon B083Z316NC）に記載なし。**ヘッダの並び（1 VIN, 2 GND, 3 SCL, 4 SDA, 5 XSHUT, 6 GPIO1）は仮。ガーバーは出さない。**ジャンパー線で接続するので、並びが違っても基板の作り直しは不要（線でつなぎ替える）。
2. NSSW157T の入数（販売ページは ¥200/パック）。
3. XIAO の 3V3 の精度・レギュレータ型番、「700 mA」の条件、カメラ表 MAX 0.65 A の条件、**5V ピンの電流能力**。
4. MOSFET の購入品の型番（AO3400A / Si2302CDS はどちらも原本で確認したが、購入品は未定）。
5. VF(10 mA) はグラフの目視。ユニット差 ±0.3 V は「2.8〜3.4 V」を typ から対称に見た近似。Vcc の幅も仮定。
6. 「nominal current の 10 %」の nominal = 80 mA という解釈。
7. ソケット・ヘッダの高さ（一般値。6 mm 制限の対象外）。**XIAO の下に置いた部品（高さ 0.9 mm 以下）が、購入するソケット・ヘッダで XIAO の底面に当たらないか**（ソケット 8.5 mm と仮定。ピンヘッダ直付けなら隙間 約 2.5 mm）。
8. Seeed の 15.25 mm は「XIAO シリーズ共通の図面」で、ESP32S3 個別の図面ではない。
9. **BoardRepo での表示**（User が手動でアップロードする。表示できたかは User の確認が要る）。
10. 頭の内部の配置（基板を頭のどこに、どの向きで取り付けるか）は未定。M2 穴は LED の縁側の 2 つの角に置いた（頭への取り付け方法が分かったら見直す）。M2 の頭の大きさ（穴のコートヤード半径 2.4 mm）は想定。
