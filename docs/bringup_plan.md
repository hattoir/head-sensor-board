**作成 2026-10-05（KiCad Agent）。** 基板はまだ発注していない。ここは「届いてからの人の作業」を、**何をどう測り、何が出れば合格か**まで決めておくための手順書。
**HARDWARE_VERIFIED = 0**（この基板の実機の測定は 1 つも無い）。以下の「期待値」は**設計からの計算値**（`docs/spec.md` §4、`tools/led_budget.py`）で、測った値ではない。**測定値を作り話で埋めない。**
所要時間はすべて Agent の**推定**。記録先 = `docs/bringup_log_YYYYMMDD.csv`（下の「返してほしい証拠」。無ければ新しく作る）。

## HG-K-01 発注の前の確認

- **目的**: シルクの文字が潰れない発注先・オプションで発注する。
- **必要な物**: `gerbers/head-sensor-board_gerbers.zip`、発注先の注文ページ、`tools/fab_rules.json` の値（2026-10-05 に公開ページから取った値。**注文して確かめた値ではない**）。
- **手順**: ①発注先を決める。②**JLCPCB の標準の文字は高さ 1.0 mm 以上が必要で、この基板は 0.8 mm**（線幅 0.15 mm）。JLCPCB を使うなら注文画面で「高精度の文字（high-precision characters、0.8 mm 以上）」を選ぶ（追加費用の有無は未確認）。PCBWay・Elecrow は文字の高さ 0.8 mm 以上・線幅 0.15 mm 以上、Seeed Fusion は 0.58 mm 以上・0.10 mm 以上が最小なので、この基板（0.8 mm・0.15 mm）のままで可。③ZIP をアップロードして、発注先のオンラインのプレビューで、外形 44 × 28 mm、穴 2.2 mm ×2（取付穴）、シルク（J1/J2 の信号名、L / R、USB-C）を目で見る。④板厚 1.6 mm、2 層、銅厚・表面処理（ここでは指定なし。手はんだなので HASL 無鉛 / ENIG どちらも可）、数量を決める。
- **測定項目**: なし（確認のみ）。
- **期待**: プレビューで外形・穴・シルクが 3D ビュー（`docs/board_3d_top_noxiao.png`）と同じに見える。
- **失敗時**: シルクが欠ける・消える → Agent に画面のスクリーンショットを渡す（文字の太さ・高さの調整、または基板の高さを 28 → 29 mm 程度にして文字を 1.0 mm にする案がある。J1/J2 の信号名の 2 段が入る帯の計算では足りる見込みだが、実際に配置・配線して確かめたものではない。再配線が要る）。
- **返してほしい証拠**: プレビューのスクリーンショット、選んだ発注先とオプション。
- **合格基準**: プレビューで 4 項目（外形・取付穴・シルク・層構成）が OK。
- **安全**: なし。**発注は User の操作**（Agent はしない）。
- **推定時間**: 約 20 分。

## HG-K-02 届いた基板の外観・寸法・刻印

- **必要な物**: ノギス（0.05 mm）、拡大鏡またはスマホのマクロ、定規、基板。
- **手順・測定項目**: ①外形 縦・横（`docs/spec.md`: 44.0 × 28.0 mm、角 R1）。②取付穴 2 つの穴径（2.2 mm）と中心の位置（右の縁から 2.1 mm、上・下の縁から 2.1 mm）。③ビア・ヘッダの穴にレジストが詰まっていないか。④シルク: J1/J2 の 6 つの名前（右から VIN GND SCL SDA XSHUT GPIO1）、L / R、USB-C の矢印、TP の名前が読めるか。⑤ pin1（四角いパッド）が J1/J2 とも**右端**か。
- **期待**: 外形 ±0.2 mm（発注先の公開仕様の外形公差）。穴 2.2 mm ±0.1。文字が読める。
- **失敗時**: 寸法が ±0.3 mm を超える・穴の位置がずれる → 写真と値を Agent に。シルクが潰れる → HG-K-01 の案。
- **返してほしい証拠**: 寸法の表（値）、基板の表・裏の写真（真上から、ピントの合ったもの）。
- **合格基準**: ①〜⑤すべて OK。
- **推定時間**: 約 15 分。

## HG-K-03 部品を載せる前の導通・短絡（基板だけ）

- **目的**: 銅の短絡・断線を、部品を載せる前に見つける（直すのが一番楽）。
- **必要な物**: テスター（導通ブザーつき）、[bringup_nets.md](bringup_nets.md)。
- **手順**: ①電源を入れずに行う。② GND（TP2）とほかの全ネットのパッド（TP1・TP3〜TP8、ヘッダのピン、ソケットのパッド）の間を、導通ブザーで当たる。③ 3V3（TP1）とほかのネットの間を当たる。④ 隣り合うパッドの間（XIAO ソケットのパッド列、J1/J2 の隣り合うピン）を当たる。
- **測定項目**: 違うネットどうし（上の ②〜④）が**すべて導通しない**こと。同じネットのパッドが導通すること（[bringup_nets.md](bringup_nets.md) の表を数本、とくに SDA/SCL/XSHUT/GATE）。
- **期待**: 違うネットどうし = 導通なし（無限大）。同じネット = 導通あり（< 1 Ω）。**GND と 3V3 が短絡していない。**
- **失敗時**: 導通した 2 点（ネット名とパッド名）を Agent に。基板の不良（銅の不良）か、ゴミ・はんだくずかを、拡大鏡で見る。
- **返してほしい証拠**: 当てた組の一覧と結果（記録 CSV）。不良があれば写真。
- **合格基準**: 違うネットどうしの導通 0 件、同じネットの断線 0 件。
- **安全**: 通電しない。
- **推定時間**: 約 30 分。

## HG-K-04 実装と、実装後の導通・短絡

- **実装の既定**: **SJ1/SJ2 は pad1-pad2 を橋渡しした状態（= LED は 3V3、R1/R2 = 20 Ω）**。5V 用の R3/R4（33 Ω 2010）は実装する（SJ が 5V 側のときだけ使う）。**R13・R14（I2C のプルアップ）と R15・R16（0 Ω リンク）は未実装（DNP）**。XIAO はソケットに載せるのを**最後**にする（HG-K-05）。NSSW157T（D1/D2）はリフローかホットエア（樹脂を押さない。カソード側 = 大きいパッド = 左）。
- **手順・測定項目**（電源を入れずに）: [bringup_nets.md](bringup_nets.md) の「当たりをつける値」の表。**3V3（TP1）↔ GND（TP2）が短絡していない**、ゲート ↔ GND ≈ 100 kΩ、U1.3/U1.4 ↔ ゲート ≈ 220 Ω、TP5/TP6 ↔ 3V3 ≈ 10 kΩ、TP7/TP8 ↔ GND ≈ 1 Ω、SJ の pad1-pad2 導通・pad2-pad3 開放、J3/J4 の + ↔ − が抵抗レンジで開放。D1/D2 の向き: ダイオードテスト（またはテスターの 3 V 以上のレンジ）で、LEDA（J3 の pin1）に赤、LEDK（pin2）に黒を当てて順方向 約 2.7〜3.2 V（点灯する場合もある）。
- **期待**: 上のとおり。**抵抗値は ±5 %（R9/R10 は ±1 %）の範囲**（テスターの誤差を含めて ±10 % まで可）。
- **失敗時**: 外れた組と値を Agent に。**通電しない。**
- **返してほしい証拠**: 測定表（値）、実装後の基板の写真（表）。
- **合格基準**: 表の全項目が期待の範囲。3V3 ↔ GND が短絡していない。
- **安全**: 通電しない。J3/J4 の + と − を絶対に短絡しない（R1 約 0.5 W / R3 約 0.7 W で焼ける）。
- **推定時間**: 約 1.5 時間（はんだ付けを除く。実装の時間は別）。

## HG-K-05 初回通電（USB だけ、ToF なし、LED 消灯）

- **必要な物**: XIAO ESP32S3 Sense（ソケットに載せる。**拡張ボードはあってもなくてもよい**）、USB の電流計（USB パワーメーター）、テスター、PC。
- **手順**: ① XIAO をソケットに載せる（USB-C が基板の左の縁）。② **ファームを書き込まずに**（または LED・I2C を出さないスケッチ）USB で給電。③ 通電直後の USB 電流を読む。④ TP1（3V3）と TP2（GND）の電圧を測る。⑤ TP7/TP8（電流検出）が 0 付近か測る。
- **測定項目**: USB の電流（mA）、TP1 の電圧、TP7・TP8 の電圧。
- **期待**: TP1 = 約 3.3 V（Agent の想定は 3.2〜3.4 V。Seeed の仕様に精度の記載なし = 仮定）。TP7・TP8 ≈ 0 mV（LED 消灯。ゲートは 100 kΩ で GND に固定）。USB の電流は XIAO 単体の値（Seeed の値は条件不明）で、**500 mA を大きく下回る**。
- **失敗時**: TP1 が 3.2 V 未満・3.4 V 超、電流が 300 mA を超える、部品が熱い → **すぐ USB を抜く**。測定値と状況を Agent に。
- **返してほしい証拠**: USB パワーメーターの写真（電流・電圧）、TP1/TP7/TP8 の値、使ったファーム（または「書き込みなし」）。
- **合格基準**: TP1 が 3.2〜3.4 V、TP7/TP8 が 10 mV 未満、USB 電流が安定。
- **安全**: 部品が熱くなったら抜く。USB は PC のポートか電流制限つきの電源。
- **推定時間**: 約 20 分。

## HG-K-06 LED 電流（3V3、PWM）の測定

- **目的**: 設計の計算（3V3 で LED 1 個 8.5 / 23.6 / 38.8 mA）が実物で当たるかを見る。T4 の「明るさ × k」の基準になる（ENTRY-K-0001）。
- **手順**: ① 左の LED（D1）: D2（GPIO3）の PWM をデューティ 10 / 50 / 100 % に。② TP7（SENSE_L）と TP2（GND）の電圧を測る（**1 Ω の抵抗の両端なので、1 mV = 1 mA**）。③ 右の LED（D2）: D3（GPIO4）で、TP8 と TP2 を同様に。④ 暗い部屋で、LED の明るさをスマホ（露出固定）で撮る。
- **測定項目**: デューティごとの TP7 / TP8 の電圧（mV）。
- **期待（計算値）**: **デューティ 100 % で 8.5〜38.8 mV（公称 23.6 mV）**。10 % は DC 換算で約 1/10（テスターは平均値を示す。PWM の周波数と、テスターの応答による）。**LED を点灯させたままケースに入れない**（5V 側は別の Gate）。
- **失敗時**: 100 % でも 8 mV 未満、または 40 mV 超 → 値と状況を Agent に（VF のばらつき、R1 の値違い、MOSFET の向き違いを調べる）。左右で大きく違う（2 倍以上）→ 同。
- **返してほしい証拠**: 測定表、LED の写真。
- **合格基準**: 100 % で 8.5〜38.8 mV の範囲（テスターの誤差を含めて ±10 %）。
- **安全**: J3/J4 に外付け LED をつなぐ場合は、**+ と − を逆にしない・短絡しない**。
- **推定時間**: 約 30 分。

## HG-K-07 ToF 小基板のピン配置の記入 → I2C・XSHUT・アドレス変更

- **必要な物**: VL53L1X 小基板 ×2（Amazon B083Z316NC）、ジャンパー線 12 本、テスター、README の対応表、I2C スキャン用のスケッチ（無ければ Agent に依頼）。
- **手順**: ① 小基板の**印字とピンの数・ピッチ**を、README の「ToF 小基板のピン配置と、ジャンパー線の対応表」に記入する（**ここが作り話にならないように、現物を見て**）。② 小基板に**プルアップ・レギュレータ・レベルシフタがあるか**をテスターで確かめる（電源を入れずに、SDA/SCL とVIN の間の抵抗、等）。③ 対応表どおりにジャンパー線を J1/J2 へつなぐ（**VIN と GND を逆にしない**）。④ XSHUT を GPIO から制御して、**両方 L → 片方を上げて I2C アドレスを変更 → もう片方を上げる**。
- **測定項目**: I2C スキャンで見えるアドレス、SDA/SCL がアイドルで H（約 3.3 V）か（TP3/TP4）。
- **期待**: ST の既定アドレスは **0x29（7 bit）**。**片方だけ起動 → 0x29 だけ**、片方を別アドレスにした後 → **2 つ見える**。SDA/SCL のアイドル = 約 3.3 V。
- **失敗時**: 何も見えない → SDA/SCL のアイドル電圧を TP3/TP4 で測る。**約 0 V または浮いている → プルアップが無い**。その場合は R13/R14（3.3 kΩ、未実装）を実装して再試験。アドレスが違う、1 つしか見えない → 値を Agent に。
- **返してほしい証拠**: 記入した対応表（写真でも可）、スキャンの出力（ログ）、TP3/TP4 の電圧。
- **合格基準**: 2 個の小基板が別アドレスで見える。
- **安全**: 電源を入れる前に VIN/GND の向きを確認。
- **推定時間**: 約 1 時間。

## HG-K-08 ソケットの高さ・Sense 拡張ボードの出っ張り・組み付け

- **必要な物**: ノギス、購入したピンソケット（1×7 ×2）、XIAO ESP32S3 Sense（拡張ボード・カメラ・microSD を付けた状態）。
- **測定項目**: ①ソケットの高さ（基板の上面から、ソケットの上端まで。**設計の仮定は 8.5 mm**）。②XIAO の底面から基板までのすきまと、XIAO の下の最も背の高い部品（C1、0805、一般値 1.25 mm 以下）の高さ。③ XIAO + 拡張ボード + カメラ + microSD カード（差した状態）の外形が、XIAO の 21 × 17.8 mm の外へ**何 mm 出るか**（USB-C と反対の端、横）。④ J1/J2 のジャンパー線のコネクタを差したとき、XIAO・拡張ボードと触れないか。
- **期待**: ①約 8.5 mm（±1）。② C1 の上と XIAO の底面のすきま ≥ 3 mm。③出っ張りは 0〜（Seeed の wiki は全体 21 × 17.8 × 15 mm。**図面での確認はまだ**）。④触れない（XIAO の縁からコネクタの縁まで約 2.4 mm の設計）。
- **失敗時**: ②のすきまが小さい（直付けにした等）→ C1 を低い品に。③出っ張りが J1/J2・LED 側へ出る → 値と写真を Agent に（配置の見直し）。
- **返してほしい証拠**: ①〜④の値、横から見た写真（ノギスを当てたもの）。
- **合格基準**: ②≥ 3 mm、③出っ張りが設計の想定（XIAO の枠内 ±0.5 mm）、④触れない。
- **推定時間**: 約 30 分。

## HG-K-09 LED を 5V にする試験（任意）

- **前提**: **HG-K-06 が合格**、かつ **XIAO の 5V 入力電流の実測（Engineering の HT-015）が済んで、USB 2.0 の 500 mA に収まる見込み**（Agent の計算では 5V 合計 493 mA = 余裕 7 mA のため、**測らずに行わない**）。
- **手順**: ① SJ1（L）の pad1-pad2 の橋を**はんだ吸い取り線で切る**。② pad2-pad3 をはんだでつなぐ。③ USB パワーメーターを挟み、TP7 の電圧を測る（HG-K-06 と同じ要領）。④ 右（SJ2）も同様。
- **期待（計算値）**: LED 1 個 **45 / 59 / 73 mA（最小/公称/最大）= TP7 で 45〜73 mV**。USB 全体は 500 mA 未満。
- **失敗時**: USB が 450 mA を超える、R3/R4 が熱い（最悪で 176 mW、定格 0.5 W の 35 %）→ 抜く。
- **返してほしい証拠**: TP7/TP8 の値、USB パワーメーターの写真。
- **合格基準**: LED 電流が 45〜73 mA、USB 電流 < 500 mA（余裕を見て 450 mA 未満が望ましい）。
- **安全**: 5V は試験用の選択肢で、**既定は 3V3**。XIAO の 5V ピンの電流能力は Seeed に記載なし = **未確認**。J3/J4 の + − の短絡で R3 が約 0.7 W を消費して焼ける。
- **推定時間**: 約 30 分。

## この手順書の限界

- 期待値は設計からの計算値。**実機で測るまで「確認済み」ではない。**
- ToF 小基板・XIAO Sense・ソケットの実物の仕様は未確認（`docs/spec.md` §8）。
- LED の光量・ToF の測距・I2C の波形の評価（T4 / T6）は、この基板の試験の後に Engineering / HG-H2 の手順で行う。
